# Sound Assets

This folder contains audio files for Bomberman XL.

## Recommended Files:

1. **explosion.mp3** - Bomb explosion sound
2. **powerup.mp3** - Power-up collection
3. **bomb_place.mp3** - Placing a bomb
4. **block_break.mp3** - Block destruction
5. **player_death.mp3** - Player death
6. **menu_click.mp3** - UI button clicks
7. **background_music.mp3** - Main game music (looping)

## Free Sound Resources:

- Freesound.org
- OpenGameArt.org
- Zapsplat.com
- Mixkit.co

## Usage:

Once you add MP3 files here, they will be automatically loaded by the SoundManager.
